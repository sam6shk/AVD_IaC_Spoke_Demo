Requirement & Scope

Why a dedicated AVD 2nd Spoke Virtual Network?

Architecture Context
🎯 Business Expectations
  • Second Spoke VNet: Connects seamlessly to existing Hub Landing Zone serving other workloads.
  • 100% Terraform IaC: Zero manual portal clickops for repeatability & compliance.
  • Simplified Host Pool Image System: Automated golden image versioning without host pool rebuilds.
  • FSLogix Profile Containers: High performance profile storage on Azure Files.
  • MSIX App Attach: Dynamic application delivery decoupled from core OS image.
💡 Key Architectural Solutions
  • Bi-directional VNet Peering with Hub VNet (`10.2.0.0/16` Spoke CIDR).
  • Forced Tunneling UDR (`0.0.0.0/0`) routing all egress traffic through Hub Firewall/NVA.
  • Azure Compute Gallery (SIG) for structured versioning (`v1.0.1` $\rightarrow$ `v1.0.2`).
  • Private Endpoints (`privatelink.file.core.windows.net`) for FSLogix & App Attach shares.
  • Entra ID Join (`AADLoginForWindows`) extension on all session host VMs.

Simplified Host Pool Image Update

Azure Compute Gallery (SIG) Rolling Updates

Image Lifecycle
1. Build & Version
  • Golden Image stored in Azure Compute Gallery (`compute_gallery.tf`).
  • Win11 Enterprise Multi-Session 23H2 + M365 Apps base definition.
  • Supports versioning (`1.0.1`, `1.0.2`, etc.).
2. Update Terraform
  • Set `use_custom_gallery_image = true`.
  • Pass `custom_image_version_id` in `terraform.tfvars`.
  • No need to destroy Host Pool workspace control plane.
3. Zero-Downtime Rollout
  • Enable Drain Mode on existing hosts.
  • Terraform provisions new host VMs from the new image version.
  • Gracefully delete old hosts after users log off.

Profile Management with FSLogix

Premium Azure Files & Automated Provisioning

Storage & Profiles
🔑 Storage Architecture
  • Premium FileStorage Account (`stfslogix...`) with ZRS replication.
  • File Share `profiles` with configurable quota (`var.fslogix_share_quota_gb`).
  • Private Endpoint in `snet-avd-private-endpoints` (`privatelink.file.core.windows.net`).
  • Public Access Disabled (`public_network_access_enabled = false`).
  • Supports Entra ID Kerberos (`AADKERB`) SMB authentication.
⚙️ Automated Host Script Inject
# Registry Config injected via CustomScriptExtension
New-Item -Path 'HKLM:\SOFTWARE\FSLogix\Profiles' -Force
New-ItemProperty -Name 'Enabled' -Value 1 -PropertyType DWORD
New-ItemProperty -Name 'VHDLocations' `
  -Value '\\stfslogix....file.core.windows.net\profiles' `
  -PropertyType MultiString
New-ItemProperty -Name 'FlipFlopProfileDirectoryName' -Value 1
New-ItemProperty -Name 'SizeInMB' -Value 30000

Dynamic App Delivery (MSIX App Attach)

Decoupling Applications from the OS Image

App Attach
📦 Package Storage Setup
  • Dedicated Storage Account (`stappattach...`) & SMB Share `appattach-packages`.
  • Secured via dedicated Private Endpoint in Spoke VNet.
  • Stores `.vhdx` / `.cim` application container packages.
🚀 Key Benefits
  • 70% Faster OS Patching: Base image stays clean and lightweight.
  • Zero App Conflicts: Apps run isolated in their own package container.
  • On-Demand Mounting: Apps mount instantly when targeted users sign in.

Security & Governance Controls

Enterprise Security Posture

Security
🛡️ Forced Tunneling

UDR on Session Host subnet routes all internet egress (`0.0.0.0/0`) through Hub NVA / Firewall for deep packet inspection.

🔒 Private Link Only

Storage accounts for FSLogix profiles & App Attach packages completely block public IP ingress.

🆔 Entra ID Identity

Session Host VMs natively joined to Entra ID via `AADLoginForWindows` extension with RBAC logon controls.
